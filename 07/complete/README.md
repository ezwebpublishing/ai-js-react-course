# SECTION 02 · 07차시 실습 (완성본)

## 주제
객체 이해하기

## 학습 목표
- 객체가 필요한 이유 이해하기
- key, value, property 이해하기
- 점 표기법으로 객체 값 접근하기
- 상품 정보를 객체로 묶기
- 추천 상품 목록을 객체 배열로 관리하기

## 실습 내용
개별 변수로 관리하던 상품 정보를 하나의 `product` 객체로 바꾸고,
추천 상품 목록도 문자열 배열에서 객체 배열로 변경합니다.

## 추가 기능
1. 대표 상품의 카테고리 출력
2. 추천 상품의 이름, 가격, 카테고리 출력
3. 객체 배열에 새 상품 추가
4. 객체 배열에서 마지막 상품 삭제

미완성본과 비교하면서 객체 구조와 점 표기법을 확인하세요.
