# SECTION 02 · 07차시 AI 프롬프트

## 1. 객체 개념 설명 요청

```text
JavaScript 객체를 코딩 초보자에게 설명해줘.
상품명, 가격, 카테고리처럼 관련 있는 정보를
하나로 묶는 예시로 설명해줘.
property, key, value, 점 표기법도 쉽게 설명해줘.
```

## 2. 데이터 구조 변경 힌트 요청

```text
상품 정보를 각각의 변수로 관리하고 있어.
productName, productPrice, discountRate처럼 흩어진 변수를
하나의 product 객체로 묶고 싶어.

또 추천 상품 배열도 단순 문자열 배열이 아니라
상품명, 가격, 카테고리를 가진 객체 배열로 바꾸고 싶어.

완성 코드를 바로 주지 말고,
1. product 객체 구조를 어떻게 만들지
2. 기존 함수에서 product.name, product.price처럼 어떻게 바꿀지
3. 객체 배열을 화면에 출력할 때 무엇이 달라지는지
단계별 힌트로 설명해줘.
```

## 3. 에러 질문

```text
문자열 배열을 객체 배열로 바꾼 뒤 화면에 [object Object]가 출력돼.
왜 이런 결과가 나오는지 설명하고,
객체의 name, price, category를 각각 꺼내 출력하는 방법을 알려줘.
```
