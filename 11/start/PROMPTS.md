# SECTION 03 · 11차시 AI 프롬프트

## 1. 구조 분리 설명 요청

```text
상품 목록 코드가 커지고 있어서 구조를 정리하고 싶어.

HTML은 main 안을 hero, search-panel, product-section, control-panel로 나누고,
JavaScript는 data.js, ui.js, events.js, script.js로 분리하려고 해.

완성 코드를 바로 주지 말고,
각 section과 각 JS 파일이 맡을 역할을 먼저 설명해줘.
```

## 2. 이벤트 힌트 요청

```text
상품 목록에서 사용자의 행동에 반응하도록 이벤트를 연결하고 싶어.

1. 상품 카드를 클릭하면 selected 클래스를 추가하기
2. 검색어 input에 입력하면 상태 메시지 변경하기
3. 카테고리 select 값이 바뀌면 상태 메시지 변경하기
4. 상품 추가/삭제 버튼을 클릭하면 목록 다시 렌더링하기

완성 코드를 바로 주지 말고,
click, input, change 이벤트를 어떤 요소에 연결해야 하는지 단계별 힌트로 설명해줘.
```

## 3. 에러 질문

```text
type="module"로 JS 파일을 분리한 뒤 import 에러가 발생해.
Live Server로 실행해야 하는 이유와
import 경로를 확인하는 방법을 알려줘.
```
