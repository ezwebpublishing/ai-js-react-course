# SECTION 04 · 24차시 실습 코드

## 차시명
검색 요구사항과 State 설계

## 이번 차시 범위
- 빈 검색어일 때 전체 상품 출력
- 대소문자를 구분하지 않는 상품명 검색
- 검색 결과 없음 안내
- 입력 중인 `keyword`와 적용된 `searchKeyword` 역할 구분
- `filter()`로 결과 배열을 만든 뒤 `map()`으로 출력

## 완료 기준
- 빈 검색어에서 상품 4개가 모두 보인다.
- `PHONE`을 검색해도 무선 헤드폰이 표시된다.
- 존재하지 않는 검색어에는 `검색 결과가 없습니다.`가 표시된다.

## 구성
- `start` (미완성본)
- `complete` (완성본)

## 이후 차시 내용 선반영 금지
이번 차시에는 다음 내용을 넣지 않았습니다.

카테고리·가격 복합 필터, 찜하기, 상품 상세

## 실행
```bash
npm install
npm run dev
```
