# SECTION 01 · 03차시 AI 프롬프트

## 1. 코드 설명 요청

```text
아래 JavaScript 코드를 코딩 초보자에게 설명해줘.
특히 const와 let의 차이, 문자열/숫자/불리언 자료형,
console.log()와 typeof를 왜 사용하는지 쉽게 설명해줘.

단, 어려운 용어보다 상품 정보 예시를 중심으로 설명해줘.
```

## 2. 힌트 요청

```text
상품명, 설명, 가격, BEST 여부를 JavaScript 변수로 저장하고
그 값을 HTML 화면에 출력하려고 해.

완성 코드를 바로 주지 말고,
1. 어떤 변수를 만들어야 하는지
2. 어떤 HTML 요소를 선택해야 하는지
3. 어떤 순서로 화면에 출력해야 하는지
힌트만 알려줘.
```

## 3. 에러 질문

```text
console에 에러가 표시돼.
내 코드와 에러 메시지를 줄 테니,
에러 원인을 초보자도 이해할 수 있게 설명하고
어느 줄을 확인해야 하는지 먼저 알려줘.
```
