## 수업 진행 방식

1. 추천 상품 배열을 만듭니다.
2. 인덱스와 length를 콘솔에서 확인합니다.
3. 배열을 화면에 목록으로 출력합니다.
4. push()와 pop()으로 배열 값을 추가·삭제합니다.
5. 배열이 바뀔 때 화면을 다시 출력합니다.
