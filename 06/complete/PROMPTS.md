# SECTION 02 · 06차시 AI 프롬프트

## 1. 배열 개념 설명 요청

```text
JavaScript 배열을 코딩 초보자에게 설명해줘.
인덱스가 0부터 시작한다는 점과 length가 무엇인지
상품 목록 예시로 설명해줘.
```

## 2. 힌트 요청

```text
추천 상품명을 배열로 저장하고 화면에 목록으로 출력하고 싶어.

배열에는 "무선 헤드폰", "스마트 워치", "블루투스 스피커"가 들어 있어.
버튼을 클릭하면 push()로 "기계식 키보드"를 추가하고,
다른 버튼을 클릭하면 pop()으로 마지막 상품을 삭제하고 싶어.

완성 코드를 바로 주지 말고,
1. 배열을 어떻게 만들지
2. 목록을 화면에 어떻게 출력할지
3. push()와 pop()을 어느 이벤트에서 사용할지
단계별 힌트로 설명해줘.
```

## 3. 에러 질문

```text
배열 값을 추가했는데 화면에 목록이 바뀌지 않아.
배열은 바뀌었는지, 화면 출력 함수를 다시 호출했는지
확인하는 순서부터 알려줘.
```
