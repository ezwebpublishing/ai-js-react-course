# SECTION 04 · 16차시 실습 (완성본)

## 주제
왜 React가 필요할까?

## 핵심 관찰

바닐라 JavaScript에서도 기능 구현은 가능합니다.
하지만 상태가 늘어날수록 다음 작업을 직접 관리해야 합니다.

1. 데이터 상태 변경
2. 현재 검색/카테고리 조건 유지
3. 목록 다시 렌더링
4. 요약 정보 다시 렌더링
5. 이벤트 흐름 충돌 방지

이 과정을 체감한 뒤 React의 `state`, `component`, `render` 개념으로 넘어갑니다.

## 학습 목표

- 상태가 화면에 영향을 주는 데이터라는 점 이해하기
- `isFavorite` 상태를 상품 데이터에 추가하기
- `toggleFavorite(id)`로 데이터 상태 변경하기
- 상태 변경 후 현재 조건을 유지한 채 다시 렌더링하기
- 바닐라 JS 구조와 React 구조 연결하기

## 실행 방법

ES Module을 사용하므로 VS Code Live Server로 실행하세요.

미완성본과 비교하면서 상태 변경 → 필터 유지 → 렌더링 흐름을 확인하세요.
