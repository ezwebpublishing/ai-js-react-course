# 상품 탐색 프로젝트 요구사항

## 사용자 요구

- 상품명을 검색해 원하는 상품을 찾는다.
- 카테고리와 최대 가격 조건을 함께 적용한다.
- 관심 상품을 찜하고 찜한 개수를 확인한다.
- 상품 상세 정보를 열고 닫는다.
- 필터를 초기화해 전체 상품으로 돌아간다.

## 완료 기준

- 빈 검색어에서는 전체 상품이 보인다.
- 검색어는 대소문자를 구분하지 않는다.
- 카테고리와 가격 조건을 동시에 만족한 상품만 보인다.
- 결과가 없거나 가격이 잘못된 경우 안내 문구가 보인다.
- 찜 상태와 상세 패널이 사용자 동작에 맞게 변경된다.

## State와 컴포넌트 책임

- `App`: 전체 State와 기능 흐름 관리
- `SearchBar`: 검색어 입력
- `FilterPanel`: 카테고리·가격 입력과 초기화
- `ProductList`: 필터 결과 목록 출력
- `ProductCard`: 상품 정보와 사용자 이벤트 연결
- `ProductDetail`: 선택한 상품 상세 표시

25차시에서는 구조만 확인하고 검색 기능은 26차시부터 구현합니다.
