# SECTION 03 · 10차시 AI 프롬프트

## 1. DOM 선택 개념 설명 요청

```text
JavaScript에서 DOM 요소를 선택한다는 것이 무슨 뜻인지 설명해줘.
querySelector()와 querySelectorAll()의 차이를
상품 카드 예시로 초보자도 이해할 수 있게 설명해줘.
```

## 2. 힌트 요청

```text
상품 객체 배열을 map()으로 화면에 카드 목록으로 출력했어.
이제 출력된 카드 요소를 JavaScript로 다시 선택해서 스타일을 바꾸고 싶어.

1. querySelector()로 첫 번째 카드 하나를 선택하는 방법
2. querySelectorAll()로 모든 카드 요소를 선택하는 방법
3. 선택한 요소에 classList.add()로 selected 클래스를 추가하는 방법
4. NodeList를 forEach로 순회하는 방법

완성 코드를 바로 주지 말고,
각 선택 방식이 언제 필요한지 비교해서 설명해줘.
```

## 3. 에러 질문

```text
querySelector(".mini-card")를 실행했는데 null이 나와.
카드가 화면에 먼저 출력되었는지, 선택자 이름이 맞는지,
코드 실행 순서를 어떻게 확인해야 하는지 알려줘.
```
