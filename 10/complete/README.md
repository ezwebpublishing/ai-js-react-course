# SECTION 03 · 10차시 실습 (완성본)

## 주제
HTML 요소 선택하기

## 학습 목표
- DOM의 의미 이해하기
- `querySelector()`로 요소 하나 선택하기
- `querySelectorAll()`로 여러 요소 선택하기
- 선택한 요소에 `classList.add()` / `classList.remove()` 적용하기
- NodeList를 `forEach()`로 순회하기

## 실습 내용
상품 카드 목록에서 다음 기능을 구현합니다.

1. 첫 번째 상품 카드 선택
2. 모든 상품 카드 선택
3. 선택 해제
4. 선택 상태 안내 문구 변경

미완성본과 비교하면서 querySelector와 querySelectorAll의 차이를 확인하세요.
