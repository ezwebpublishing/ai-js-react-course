## 수업 진행 방식

1. map()으로 출력된 상품 카드 목록을 확인합니다.
2. querySelector()로 첫 번째 카드를 선택합니다.
3. querySelectorAll()로 모든 카드를 선택합니다.
4. classList로 selected 클래스를 추가·삭제합니다.
5. 완성본과 비교합니다.
