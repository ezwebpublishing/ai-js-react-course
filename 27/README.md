# SECTION 05 · 27차시 실습 코드

## 차시명
카테고리·가격 복합 필터 구현하기

## 이번 차시 범위
- selectedCategory State 만들기
- maxPrice State 만들기
- FilterPanel 컴포넌트 만들기
- 카테고리 버튼과 가격 입력창을 State와 연결하기
- 검색어, 카테고리, 가격 조건을 함께 filter()에 적용하기

## 구성
- `start` (미완성본)
- `complete` (완성본)

## 실행
```bash
npm install
npm run dev
```

## 이후 차시 내용 선반영 금지
이번 차시에는 다음 내용을 넣지 않았습니다.

- 정렬 기능
- 찜하기
- 상품 상세
- 상품 추가·삭제
- AI 코드 리뷰 및 리팩터링

27차시는 26차시 상품명 검색 기능에 **카테고리와 가격 조건만 추가**하는 단계입니다.

## 완료 기준
- 검색어, 카테고리, 최대 가격 조건이 함께 적용된다.
- 카테고리 `전체`와 빈 가격은 해당 조건을 제한하지 않는다.
- 여러 조건을 만족하는 상품이 없으면 안내 문구가 보인다.
