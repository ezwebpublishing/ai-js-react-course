# SECTION 03 · 13차시 AI 프롬프트

## 1. 데이터 렌더링 흐름 설명 요청

```text
상품 데이터 배열을 HTML 카드 목록으로 바꾸는 흐름을 설명해줘.
products 배열, createProductCardHTML(), map(), join(""), innerHTML이
각각 어떤 역할을 하는지 초보자도 이해할 수 있게 설명해줘.
```

## 2. 렌더링 함수 힌트 요청

```text
상품 목록 코드를 data.js, ui.js, events.js, script.js로 분리했어.

products 배열의 상품 객체를 화면 카드 HTML로 바꾸는
createProductCardHTML(product) 함수와
상품 배열 전체를 화면에 출력하는 renderProducts(products) 함수를 정리하고 싶어.

완성 코드를 바로 주지 말고,
1. 상품 데이터 구조에 어떤 속성이 필요한지
2. 카드 HTML 문자열에 어떤 정보가 들어가야 하는지
3. map()과 join("")이 각각 어떤 역할을 하는지
4. 상품이 0개일 때 빈 상태 메시지를 어떻게 처리할지
단계별 힌트로 설명해줘.
```

## 3. 에러 질문

```text
상품 데이터는 있는데 화면에 카드가 표시되지 않아.
productItems 배열, productHTML 배열, join("") 결과,
productList.innerHTML 대입 여부를 어떤 순서로 확인하면 좋을지 알려줘.
```
