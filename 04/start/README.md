# SECTION 02 · 04차시 실습 (미완성본)

## 주제
연산자와 조건문

## 학습 목표
- 산술 연산자로 할인 가격 계산하기
- 비교 연산자로 조건 판단하기
- `if / else`로 다른 화면 문구 출력하기
- 상품 카드에 무료배송, 할인, 구매 가능 상태 표시하기

## 실습 내용
상품 가격, 할인율, 재고 여부를 기준으로 다음 기능을 구현합니다.

1. 할인율에 따른 최종 가격 계산
2. 할인 배지 표시
3. 무료배송 여부 표시
4. 재고 여부에 따른 구매 가능/품절 표시
5. 찜 횟수가 3 이상일 때 다른 안내 문구 출력
