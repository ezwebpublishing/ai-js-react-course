# SECTION 02 · 04차시 AI 프롬프트

## 1. 조건식 힌트 요청

```text
상품 가격, 할인율, 재고 여부를 변수로 저장하고 있어.
가격이 50,000원 이상이면 '무료배송',
아니면 '배송비 3,000원'을 출력하고 싶어.

또 할인율이 0보다 크면 할인 배지를 보여주고,
재고가 없으면 '품절' 문구를 보여주고 싶어.

완성 코드를 바로 주지 말고,
어떤 조건식을 만들어야 하는지 먼저 설명해줘.
그리고 if / else 구조를 단계별로 힌트로 알려줘.
```

## 2. 코드 설명 요청

```text
아래 JavaScript 코드에서 산술 연산자, 비교 연산자, 논리적인 판단이
각각 어디에 사용되었는지 초보자도 이해할 수 있게 설명해줘.
상품 가격과 배송 조건 예시로 설명해줘.
```

## 3. 에러 질문

```text
if 문을 작성했는데 원하는 문구가 출력되지 않아.
내 코드와 현재 화면 결과를 줄 테니,
조건식이 true인지 false인지 확인하는 방법부터 알려줘.
```
