## 수업 진행 방식

1. 미완성본을 실행합니다.
2. 상품 가격, 할인율, 재고 여부 변수를 확인합니다.
3. 연산자로 할인 가격을 계산합니다.
4. if / else로 무료배송, 할인, 재고 상태를 출력합니다.
5. 완성본과 비교합니다.
