## 수업 진행 방식

1. for 반복문으로 상품명을 콘솔에 출력합니다.
2. forEach로 배열을 순회합니다.
3. map으로 상품명 배열과 카드 HTML 배열을 만듭니다.
4. join("")으로 HTML 문자열을 합쳐 화면에 출력합니다.
5. 완성본과 비교합니다.
