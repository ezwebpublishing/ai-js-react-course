# SECTION 02 · 08차시 AI 프롬프트

## 1. for / forEach / map 비교 요청

```text
JavaScript에서 for, forEach, map의 차이를 초보자도 이해할 수 있게 설명해줘.
상품 객체 배열을 예시로 설명하고,
각각 언제 사용하면 좋은지도 비교해줘.
```

## 2. map 힌트 요청

```text
상품 객체 배열을 화면에 카드 목록으로 출력하고 싶어.

현재 products 배열에는 name, price, category, discountRate가 들어 있어.
forEach로 목록을 출력하는 방법과
map()으로 HTML 문자열 배열을 만든 뒤 join()으로 합쳐 출력하는 방법을 비교하고 싶어.

완성 코드를 바로 주지 말고,
1. forEach 방식의 흐름
2. map() 방식의 흐름
3. React에서 map()을 자주 쓰는 이유
를 단계별로 설명해줘.
```

## 3. 에러 질문

```text
map()으로 만든 HTML이 화면에 쉼표와 함께 출력돼.
왜 이런 일이 생기는지 설명하고,
join("")을 왜 사용하는지 알려줘.
```
