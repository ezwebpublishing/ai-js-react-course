# SECTION 02 · 08차시 실습 (완성본)

## 주제
반복문에서 map까지

## 학습 목표
- `for` 반복문 이해하기
- `forEach()`로 배열 순회하기
- `map()`으로 새로운 배열 만들기
- 객체 배열을 HTML 문자열로 변환하기
- React에서 `map()`이 중요한 이유 이해하기

## 실습 내용
추천 상품 객체 배열을 두 방식으로 화면에 출력합니다.

1. `forEach()`로 `<li>` 목록 출력
2. `map()`으로 카드 HTML 문자열 배열 생성
3. `join("")`으로 HTML 문자열 합치기
4. 상품 추가·삭제 시 두 목록 모두 다시 출력

미완성본과 비교하면서 forEach와 map의 차이를 확인하세요.
