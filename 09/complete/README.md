# SECTION 02 · 09차시 실습 (완성본)

## 주제
React를 위한 최신 JavaScript

## 학습 목표
- 화살표 함수 이해하기
- 템플릿 리터럴 복습하기
- 구조분해 할당으로 객체 값 꺼내기
- spread로 새 배열 만들기
- 삼항연산자로 조건에 따라 값 선택하기
- React에서 자주 쓰는 JavaScript 스타일에 익숙해지기

## 실습 내용
8차시 상품 목록 코드를 React에서 자주 사용하는 JavaScript 문법으로 리팩터링합니다.

## 적용 문법
1. `function` → 화살표 함수
2. `product.name` → 구조분해 할당
3. `push()` → spread
4. `pop()` → `slice(0, -1)`
5. `if / else` 일부 → 삼항연산자

미완성본과 비교하면서 React식 JavaScript 문법의 차이를 확인하세요.
