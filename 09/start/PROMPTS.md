# SECTION 02 · 09차시 AI 프롬프트

## 1. 최신 JavaScript 문법 설명 요청

```text
React를 배우기 전에 알아야 할 최신 JavaScript 문법을 설명해줘.
화살표 함수, 템플릿 리터럴, 구조분해 할당, spread, 삼항연산자를
상품 목록 코드 예시로 설명해줘.
```

## 2. 리팩터링 힌트 요청

```text
현재 상품 목록 코드는 잘 동작하지만 React에서 자주 쓰는 문법으로 정리하고 싶어.

다음 문법을 적용하고 싶어.
1. function 선언을 화살표 함수로 변경
2. product.name 대신 구조분해 할당 사용
3. push() 대신 spread로 새 배열 만들기
4. if / else 중 일부를 삼항연산자로 변경

완성 코드를 바로 주지 말고,
각 문법이 왜 React 학습에 도움이 되는지 설명하고
어떤 함수부터 바꾸면 좋은지 순서대로 제안해줘.
```
