# 최종 테스트 체크리스트

## 자동 검증
- `npm run test`가 통과하는가?
- `npm run build`가 오류 없이 끝나는가?

## 검색
- 상품명을 입력하면 목록이 줄어드는가?
- 검색어를 지우면 전체 목록이 다시 보이는가?

## 카테고리·가격 필터
- 카테고리를 클릭하면 해당 분류만 보이는가?
- 최대 가격을 입력하면 해당 가격 이하 상품만 보이는가?
- 음수 가격을 입력하면 안내 메시지가 보이는가?

## 찜하기
- 찜하기 버튼을 누르면 문구가 바뀌는가?
- 찜한 상품 개수가 바뀌는가?

## 상품 상세
- 상세 보기 버튼을 누르면 상세 패널이 열리는가?
- 상세 닫기 버튼으로 패널이 닫히는가?

## 초기화
- 필터 초기화 버튼을 누르면 검색어, 카테고리, 가격, 상세 패널이 초기화되는가?

## AI 제안 판단
- 적용한 제안과 보류한 제안의 이유를 설명할 수 있는가?
- 리팩터링 전후에 기능과 테스트 결과가 같은가?
