# SECTION 05 · 30차시 실습 코드

## 차시명
AI 코드 리뷰와 리팩터링 · 프로젝트 완성

## 이번 차시 범위
- Copilot으로 현재 파일의 오류와 작은 수정 후보 확인
- Claude Code로 여러 파일의 구조, 테스트 누락, 역할 중복 검토
- 제안별 적용 여부와 이유 판단
- `npm run test`로 핵심 계산 로직 검증
- `npm run build`와 사용자 시나리오로 프로젝트 최종 확인

## 구성
- `start` (미완성본)
- `complete` (완성본)
- `AI_CODE_REVIEW_PROMPT.md`
- `FINAL_TEST_CHECKLIST.md`

## 실행
```bash
npm install
npm run dev
npm run test
npm run build
```

## 기준
30차시는 새 기능을 추가하지 않고, 29차시까지 완성한 프로젝트를 AI 코드 리뷰와 리팩터링 관점으로 정리하는 마무리 단계입니다. AI 제안은 바로 적용하지 않고 완료 기준, 테스트, 빌드 결과를 근거로 선택합니다.
