# AI 코드 리뷰 요청 프롬프트

React 상품 탐색 앱이 완성된 상태야.
현재 기능은 검색, 카테고리 필터, 가격 필터, 찜하기, 상품 상세 보기, 필터 초기화, 결과 없음 처리가 있어.

이제 새 기능을 추가하지 말고 최종 코드 리뷰와 리팩터링만 하고 싶어.

다음 기준으로 리뷰해줘.

1. 컴포넌트 역할이 적절히 분리되어 있는지
2. App.jsx에서 함수로 분리하면 좋은 로직이 있는지
3. 변수명과 함수명이 초보자가 이해하기 쉬운지
4. 사용자가 테스트해야 할 기능 체크리스트
5. 수정 전후로 반드시 확인해야 할 동작

완성 코드를 바로 주기보다, 개선이 필요한 이유와 수정 순서를 먼저 설명해줘.
