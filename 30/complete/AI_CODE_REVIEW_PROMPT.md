# Claude Code 프로젝트 리뷰 요청 프롬프트

React 상품 탐색 앱이 완성된 상태야.
현재 기능은 검색, 카테고리 필터, 가격 필터, 찜하기, 상품 상세 보기, 필터 초기화, 결과 없음 처리가 있어.

이제 새 기능을 추가하지 말고 최종 코드 리뷰와 리팩터링만 하고 싶어.

여러 파일을 함께 살펴보고 다음 기준으로 리뷰해줘.

1. 컴포넌트 역할이 적절히 분리되어 있는지
2. App.jsx에서 함수로 분리하면 좋은 로직이 있는지
3. 변수명과 함수명이 초보자가 이해하기 쉬운지
4. 사용자가 테스트해야 할 기능 체크리스트
5. 수정 전후로 반드시 확인해야 할 동작
6. 기존 Vitest 테스트에서 빠진 경계 조건
7. `npm run build` 실패 가능성이 있는 import 또는 문법 문제

각 제안을 `필수`, `권장`, `보류 가능`으로 구분하고 이유를 설명해줘. 완성 코드를 바로 주지 말고 수정할 파일과 검증 순서를 먼저 제안해줘.

## Copilot에 요청할 범위

현재 열어 둔 파일의 코드 설명, 작은 오류 수정, 함수명 개선처럼 한 파일 안에서 끝나는 작업에 사용합니다.
