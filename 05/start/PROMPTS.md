# SECTION 02 · 05차시 AI 프롬프트

## 1. 함수 분리 제안 요청

```text
아래 JavaScript 코드는 상품 가격, 할인, 배송 문구를 처리하고 있어.
기능은 동작하지만 코드가 길어져서 읽기 어렵다.

완성 코드를 바로 주지 말고,
어떤 부분을 함수로 분리하면 좋은지 먼저 제안해줘.

특히 다음 작업을 함수로 나누고 싶어.
1. 가격을 89,000원 형식으로 바꾸기
2. 할인 가격 계산하기
3. 배송 문구 만들기
4. 상품 정보를 화면에 출력하기

각 함수의 이름과 역할을 먼저 설명해줘.
```

아래 코드에서 함수 이름, 매개변수, return이 각각 어떤 역할을 하는지 설명해줘.
