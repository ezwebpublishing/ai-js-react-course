# SECTION 01 · 02차시 실습 (완성본)

## 주제
AI를 코딩 학습에 활용하는 방법

## 실습 목표
1차시에서 만든 찜하기 코드에 **초기화 버튼**을 추가합니다.

## 핵심 학습
- AI에게 완성 코드를 바로 요청하지 않기
- 설명 요청, 힌트 요청, 수정 요청, 에러 질문 구분하기
- 기존 코드를 유지하면서 필요한 기능만 추가하기

## 추가할 기능
초기화 버튼을 클릭하면:

1. `count`가 0으로 변경됩니다.
2. 화면의 숫자가 0으로 변경됩니다.
3. 안내 문구가 처음 문구로 돌아갑니다.
4. 찜하기 버튼의 `active` 클래스가 제거됩니다.
