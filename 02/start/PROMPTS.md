# SECTION 01 · 02차시 AI 프롬프트 실습

## 1. 설명 요청

```text
아래 JavaScript 코드를 코딩을 처음 배우는 사람에게 설명해줘.
특히 querySelector, addEventListener, textContent, classList가
각각 어떤 역할을 하는지 쉬운 말로 설명해줘.
```

## 2. 힌트 요청

```text
HTML/CSS로 만든 상품 카드에 JavaScript 기능을 추가하고 있어.
현재 찜하기 버튼은 클릭하면 숫자가 증가해.

이번에는 '초기화' 버튼을 추가해서
count를 0으로 바꾸고, 안내 문구를 처음 문구로 되돌리고,
찜하기 버튼의 active 클래스를 제거하고 싶어.

완성 코드를 바로 주지 말고,
어떤 HTML, CSS, JavaScript 부분을 수정해야 하는지
3단계 힌트로 먼저 설명해줘.
```

## 3. 수정 요청

```text
아래 코드에서 기존 찜하기 기능은 유지하고,
초기화 버튼 기능만 추가하려고 해.
수정해야 하는 파일과 위치를 먼저 알려주고,
그 다음 필요한 코드만 제안해줘.
```

## 4. 에러 질문

```text
초기화 버튼을 클릭하면 에러가 발생해.
에러 메시지와 코드를 함께 줄 테니,
원인을 먼저 설명하고 수정 방향을 알려줘.
완성 코드를 바로 주기보다 내가 확인할 부분을 순서대로 알려줘.
```
