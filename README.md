# AI와 함께 배우는 JS → React 실습 소스

이 저장소는 **JavaScript 기초부터 React 프로젝트 완성까지** 단계별로 학습할 수 있도록 구성한 강의 실습 소스입니다.

각 차시는 `01`부터 `30`까지 독립된 폴더로 구성되어 있으며, 특정 차시의 코드를 바로 열어 확인하거나 실습을 시작할 수 있습니다.

---

## 과정 안내

총 **30차시**로 구성되어 있습니다.

```text
ai-js-react-course/
├─ 01/
├─ 02/
├─ 03/
├─ ...
├─ 29/
└─ 30/
```

차시별로 UI와 기능 구현 범위가 다르기 때문에, 하나의 프로젝트를 계속 수정하는 방식이 아니라 **차시별 독립 소스**로 관리합니다.

특히 후반 프로젝트 구간은 다음과 같이 단계적으로 기능이 확장됩니다.

```text
25차시 → 프로젝트 설계와 기본 구조
26차시 → 상품 검색
27차시 → 카테고리·가격 복합 필터
28차시 → 찜하기·상품 상세
29차시 → 기능 통합·예외 처리
30차시 → AI 코드 리뷰·리팩터링
```

---

## 소스 사용 방법

### 1. 원하는 차시 폴더 열기

예를 들어 27차시를 실습하려면 다음 폴더를 엽니다.

```text
27/
```

VS Code에서 해당 차시 폴더를 직접 여는 것을 권장합니다.

---

### 2. 패키지 설치

React / Vite 프로젝트는 처음 실행할 때 해당 차시 폴더에서 아래 명령을 실행합니다.

```bash
npm install
```

`node_modules`는 GitHub 저장소에 포함되지 않으므로 각 차시에서 처음 실행할 때 설치가 필요합니다.

---

### 3. 개발 서버 실행

```bash
npm run dev
```

터미널에 표시되는 Local 주소를 브라우저에서 열어 결과를 확인합니다.

예:

```text
http://localhost:5173
```

## 미완성본과 완성본 사용 방법

차시에 따라 다음과 같이 구성할 수 있습니다.

```text
start/
complete/
```

### 미완성본 / start

강의를 따라 실습할 때 사용하는 시작 코드입니다.

### 완성본 / complete

해당 차시의 실습이 모두 완료된 결과 코드입니다.

권장 학습 흐름은 다음과 같습니다.

```text
미완성본으로 시작
      ↓
강의를 따라 코드 작성
      ↓
브라우저에서 결과 확인
      ↓
완성본과 비교
```

---

## 차시별 소스 사용 기준

각 차시는 **해당 수업 시점의 코드 상태**를 기준으로 구성합니다.

따라서 다음 차시에서 배울 기능을 이전 차시에 미리 구현하지 않는 것을 원칙으로 합니다.

수업 중에는 현재 차시 폴더만 열어서 진행하고, 다른 차시의 파일을 덮어쓰지 않는 것을 권장합니다.

---

## 권장 실습 흐름

```text
1. 해당 차시 폴더 열기
2. 미완성본 또는 start 폴더 확인
3. npm install
4. npm run dev
5. 강의를 따라 코드 작성
6. 브라우저에서 결과 확인
7. 완성본 또는 complete 폴더와 비교
```

---

## 주의사항

- 각 차시의 `node_modules` 폴더는 GitHub에 업로드하지 않습니다.
- `.env` 파일에 API Key나 비밀번호가 있는 경우 절대 GitHub에 올리지 마세요.
- React/Vite 프로젝트는 각 차시 폴더에서 `npm install` 후 실행합니다.
- 차시별 코드 구조와 UI가 다를 수 있으므로 다른 차시의 파일을 임의로 덮어쓰지 않는 것을 권장합니다.
