# SECTION 03 · 12차시 AI 프롬프트

## 1. DOM 변경 방식 설명 요청

```text
JavaScript에서 textContent, innerHTML, classList, style의 차이를 설명해줘.
상품 카드 목록 예시로 어떤 상황에서 무엇을 사용하면 좋은지 비교해줘.
```

## 2. 구조 분리 상태에서 스타일 변경 힌트 요청

```text
상품 목록 코드를 data.js, ui.js, events.js, script.js로 분리했어.

검색어 input과 카테고리 select 값에 따라
조건에 맞는 상품 카드에는 highlight 클래스를 추가하고
조건에 맞지 않는 상품 카드에는 dimmed 클래스를 추가하고 싶어.

완성 코드를 바로 주지 말고,
1. UI 변경 함수는 ui.js에 두는 이유
2. 이벤트 함수는 events.js에 두는 이유
3. data-name, data-category 값을 어떻게 활용할지
4. classList.toggle()로 상태를 바꾸는 흐름
을 단계별 힌트로 설명해줘.
```
