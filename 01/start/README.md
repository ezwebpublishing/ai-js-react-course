## 이번 차시 목표

JavaScript가 왜 필요한지 이해합니다.

## 역할 구분
- HTML = 구조
- CSS = 디자인
- JavaScript = 동작

## 실습
교안의 첫 실습과 동일하게 '찜하기' 버튼을 구현합니다.

버튼을 클릭하면:
1. 클릭 이벤트를 감지합니다.
2. 찜 횟수 데이터를 변경합니다.
3. 화면의 숫자와 문구를 변경합니다.
4. 버튼에 `active` 클래스를 추가합니다.
